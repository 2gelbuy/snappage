## 2. User Pain Points (from Exa research + Reddit + support forums)

### Top Complaints Across All Competitors (ordered by frequency)

1. **Breaks after Chrome updates** — FireShot #1 issue (multiple forum threads), GoFullPage v8.6 had to fix for LLM chat UIs
2. **Subscription fatigue** — GoFullPage $1/mo gets pushback ("I would love to support if you could provide a one time lifetime access" — real review Mar 2026)
3. **Can't capture complex pages** — SPAs, lazy-loaded images, infinite scroll, sticky headers
4. **Privacy concerns** — Awesome Screenshot uploads to cloud. Users want local-only
5. **Missing free editor** — GoFullPage locks editing behind paywall
6. **Poor PDF export** — DevTools misses lazy-loaded images, duplicates fixed headers
7. **No text extraction** — OCR requested across all competitors
8. **Generic file names** — All competitors use "screenshot_2026.png" naming

### Features Users Actively Request (from reviews + forums)
- URL + timestamp in screenshot (Screenshot with URL proves demand)
- Element-level capture (Pluck proves demand)
- Device frame mockups (Captio proves demand)
- Auto-blur PII before sharing
- Batch capture of multiple URLs
- Direct share to Slack/Notion/Jira

## 3. CWS SEO Strategy (from Extension Ranker research)

### How CWS Ranking Works (2026)
Source: extensionranker.com — data-driven analysis of CWS ranking signals

**Two core dimensions:**
1. **Relevance** — title, short description, full description match user query
2. **Product Quality** — ratings, reviews, downloads, uninstalls, usage stats

**"Tiered Bracket Mechanism":**
- Relevance determines if you compete in the top tier
- Quality signals are the tiebreaker among similar-relevance extensions
- Extensions with <100 users CAN outrank 1000+ user extensions if relevance is higher

### Target Keywords (prioritized)

| Keyword | Competition | Strategy |

| `full page screenshot` | VERY HIGH (GoFullPage 10M) | Must be in title, long-term play |

## 4. Pricing Strategy (Updated)

### Key Insight from MiroMiro Case Study (March 2026)
"I got 5 paying customers in a row after adding the lifetime plan"
- Chrome extensions are TOOLS, not platforms
- Users expect to BUY tools, not RENT them
- Lifetime pricing converts 3-5x better than subscriptions for utility extensions

### Updated Pricing

| Tier | Price | Features |
|------|-------|----------|
| **Free** | $0 | Full page + visible + area capture, basic editor (crop, arrows, text, blur), PNG/JPEG, auto-naming, keyboard shortcut, unlimited captures |
| **Pro** | **$29 lifetime** (highlight this) OR $3/mo | OCR text extraction, smart PII redaction, PDF export, device frame mockups, responsive batch capture, custom watermark |

### Why NOT charge for PDF
FireShot charges $40-100 for PDF. GoFullPage includes PDF free. Our positioning: **PDF export is FREE** — this alone differentiates from FireShot and attracts their disgruntled users.

### Revenue Model
- 0.5% of GoFullPage's 10M users = 50K users
- 2% conversion at $29 lifetime = $29K
- Plus $3/mo subscribers = recurring base
- Target: $8K/mo by month 12
